# silpo-alco-watch

Контейнер, що стежить за акціями на алкоголь у конкретній філії Сільпо
і публікує нові знижки з фото в Telegram-групу.

## Як воно працює

Ходить напряму в публічний storefront API Сільпо
(`https://sf-ecom-api.silpo.ua`) — той самий бекенд, який живить silpo.ua.
Ключі, OAuth і LLM не потрібні: жодних витрат, жодних залежностей від
зовнішніх сервісів, окрім самого Сільпо і Telegram.

За прохід (раз на добу):

1. тягне дерево категорій філії й розкручує його до **листових** категорій
   (API віддає товари тільки для них — запит по «Алкоголь» поверне 0);
2. обходить **увесь** алкогольний каталог, не лише акційні плашки
   (~1600 позицій, ~10 секунд);
3. пише в архів кожну зміну ціни;
4. рахує реальну знижку відносно власної базової ціни;
5. шле в Telegram топ-1 з фото, динамікою ціни й попередженням про накрутку.

## Чому не можна вірити плашці

Сільпо часто піднімає ціну перед акцією: −35% на цінник, а по факту товар
коштує стільки ж. API **історію цін не віддає** — є лише поточна ціна,
перекреслена `oldPrice` і вікно акції `startAt`/`stopAt`. Тому архів
доводиться вести самим.

Базова ціна рахується як **медіана цін поза акцією, зважена на кількість
днів**, що ціна протрималась. Саме зважування ламає схему «підняли на
3 дні — і знизили»: короткий сплеск не перебиває ціну, що стояла місяць.

    заявлено   −35%   (999 → 649)
    насправді  −19%   (звичайна ціна 799)
    ⚠️ перекреслену ціну підняли перед акцією

Поки історії менше 7 днів, висновків бот не робить і чесно пише
«історія цін: N дн. — ще збираю». Нормальна статистика набереться
приблизно за місяць.

## Налаштування

```bash
cp .env.example .env
```

Далі два значення, які треба дізнатись.

**branchId філії:**

```bash
docker compose run --rm silpo-alco-watch branches --search "Львів"
```

**chat_id групи** — додай бота в групу, напиши там `/start@<бот>`, потім:

```bash
docker compose run --rm silpo-alco-watch chatid
```

> Кілька філій у `SILPO_BRANCHES` розділяються **крапкою з комою**,
> бо назва філії сама містить кому:
> `id1:Сільпо, вул. А; id2:Сільпо, вул. Б`

## Запуск

```bash
docker compose up -d --build
docker compose logs -f
```

## Команди

| Команда | Що робить |
|---|---|
| `watch` | постійний режим за розкладом (за замовчуванням) |
| `history` | статистика зібраного архіву цін |
| `run` | один прохід і вихід |
| `test` | надіслати тестове повідомлення в чат |
| `chatid` | показати chat_id, які бачить бот |
| `branches --search "…"` | знайти branchId за містом/адресою |
| `config` | показати поточну конфігурацію |

Перевірити, що саме піде в чат, нічого не надсилаючи і не змінюючи стан:

```bash
docker compose run --rm -e DRY_RUN=true silpo-alco-watch run
```

## Скільки це повідомлень

Заміри по філії на просп. Івасюка (серпень 2026), групи
`strong,beer,cider,vermouth` — 605 акційних позицій у наявності:

| Поріг `MIN_DISCOUNT_PERCENT` | Позицій |
|---|---|
| 0 (будь-яка) | 605 |
| 15 | 536 |
| 20 | 463 |
| 25 | 297 |
| 30 | 160 |
| 40 | 33 |
| 50 | 8 |

Це разовий зріз — після сідування в чат ітимуть лише **нові** акції.
`MAX_MESSAGES_PER_RUN` обмежує один прохід (топ за знижкою);
решта не позначається як надіслана і піде наступного разу.

## Команди в чаті

Бот відповідає на команду товаром із найбільшою знижкою в категорії:

| Команда | Категорія |
|---|---|
| `/топ` `/top` | уся акційна поличка |
| `/горілка` `/vodka` | горілка |
| `/пиво` `/beer` | пиво |
| `/крафт` `/craft` | крафтове пиво |
| `/віскі` `/whisky` | віскі |
| `/коньяк` `/brandy` | коньяк і бренді |
| `/ром` `/rum` · `/джин` `/gin` · `/текіла` `/tequila` | відповідно |
| `/лікер` `/liqueur` · `/настоянка` | лікери, настоянки |
| `/вермут` `/vermouth` · `/сидр` `/cider` | вермути, сидр |
| `/вино` `/wine` · `/ігристе` `/sparkling` | вина |
| `/help` | список команд |

Зареєструвати латинські команди в меню бота (кирилицю Telegram у меню не приймає):

```bash
docker compose run --rm silpo-alco-watch setcommands
```

> **Кирилиця в групах.** Telegram вважає командою лише `/ascii`, тому
> privacy-режим відсіює `/горілка` ще на своєму боці. Щоб кириличні команди
> працювали в групі, бот має бути **адміністратором** групи (адмінам віддаються
> всі повідомлення) або privacy треба вимкнути в @BotFather → `/setprivacy`.
> У приватному чаті з ботом кирилиця працює завжди.

Відповіді кешуються на 10 хвилин, повтор тієї самої команди — не частіше
ніж раз на 5 секунд.

## Веб-дашборд

Працює в тому ж контейнері окремим потоком, на стандартній бібліотеці —
жодних веб-фреймворків. Порт назовні контейнер не публікує: до нього
ходить лише reverse-proxy, він же тримає авторизацію.

| Сторінка | Що показує |
|---|---|
| `/` | KPI, топ-10 реальних знижок, порівняння магазинів, подешевшало за добу |
| `/cross-store` | той самий товар із різною ціною в двох магазинах |
| `/fakes` | «зал ганьби» — де ціну підняли перед акцією |
| `/index` | медіанна ціна по категоріях за 30 днів |
| `/product?b=&p=` | картка товару з графіком ціни й порівнянням магазинів |
| `/search?q=` | пошук за назвою |
| `/api/overview` | ті самі KPI у JSON |
| `/healthz` | перевірка живості |

Верстка **mobile-first**: близько 90% заходів з телефона, тому таблиці
замінені картками, тап-цілі не менші за 44 px, а графіки рендеряться
як inline SVG з viewBox під вузький екран.

Підняти лише дашборд, без розкладу і бота:

```bash
docker compose run --rm -p 8080:8080 silpo-alco-watch web
```

## Стан

SQLite у іменованому томі `silpo-state` (`/data/state.db` усередині
контейнера). Позиція, якої не було в акціях
`PRUNE_AFTER_DAYS` днів, забувається — щоб акція, яка повернулась
через місяць, знову вважалась новою.

Скинути й почати з чистого аркуша:

```bash
docker compose down -v && docker compose up -d
```
